# Delete Or Merge Review Cadence

Review this repository after every `agent-failure-packet` release.

## Questions

1. Did any failure-packet work need trace fields not listed in `docs/evidence-wedge.md`?
2. Did any user ask for a dashboard, or did they only need shareable evidence?
3. Can the idea be merged into `agent-failure-packet` without creating a new product?
4. Should any stale idea be deleted?

## Actions

- Merge useful packet-shaped fields into `agent-failure-packet`.
- Delete concepts that point toward a generic dashboard.
- Keep reopen criteria explicit.
- Do not add code here without a new product decision.
